# kampo-care-android

치매 및 혀 상태 카메라 진단 React Native 앱 (Expo).

## Stack

- React Native 0.81 · Expo 54 · TypeScript
- NativeWind (Tailwind CSS) · Zustand · React Navigation
- expo-camera · axios

## Features

- 카메라 기반 치매 진단
- 혀 상태 촬영 및 분석
- 진단 모드 전환

## Run

```bash
npx expo start
npx expo run:android
```
